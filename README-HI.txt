अखिल भारतीय सांस्कृतिक विकास महासंघ — Static Website

यह वेबसाइट केवल HTML, CSS और JavaScript से बनाई गई है। इसमें PHP, WordPress,
MySQL या किसी database की आवश्यकता नहीं है। यह Razorhost के सामान्य shared hosting
plan पर चलने के लिए तैयार है।

Razorhost पर अपलोड करने के चरण:
1. Razorhost के cPanel में Login करें।
2. File Manager खोलें।
3. अपने domain के document root में जाएँ (मुख्य domain के लिए सामान्यतः public_html)।
4. इस ZIP को upload करें और Extract करें।
5. सुनिश्चित करें कि index.html सीधे public_html के अंदर हो, किसी अतिरिक्त folder के अंदर नहीं।
6. अपना domain खोलकर वेबसाइट जाँचें। cPanel में SSL उपलब्ध हो तो HTTPS/SSL सक्रिय करें।

संपादन:
- index.html: वेबसाइट का टेक्स्ट, फोन, ईमेल और पते में बदलाव।
- styles.css: रंग, spacing, layout और responsive design।
- script.js: मोबाइल मेन्यू और हिंदी/English भाषा बदलने का विकल्प।
- assets/favicon.svg: ब्राउज़र टैब का लोगो।

महत्वपूर्ण:
- सदस्यता शुल्क ₹211 (प्रदेश) और ₹151 (जिला) उपलब्ध कराए गए परिचय-पत्र से लिए गए हैं।
  प्रकाशित करने से पहले वर्तमान शुल्क की पुष्टि कर लें।
- वेबसाइट में कोई backend form नहीं है; कॉल, ईमेल और मैप लिंक सीधे खुलते हैं।
- Google Fonts के लिए इंटरनेट कनेक्शन होने पर Noto Sans Devanagari और DM Sans लोड होंगे;
  अन्यथा सिस्टम के उपलब्ध fonts उपयोग होंगे।
- पंजीकरण संबंधी वाक्य और अन्य संस्थागत विवरण उपलब्ध brochure के आधार पर रखे गए हैं।
