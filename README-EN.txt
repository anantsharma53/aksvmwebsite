Akhil Bharatiya Sanskritik Vikas Mahasangh — Static Website

This website uses plain HTML, CSS and JavaScript. It does not require PHP,
WordPress, MySQL or a database and is suitable for an ordinary Razorhost shared
hosting plan.

Upload to Razorhost:
1. Sign in to Razorhost cPanel.
2. Open File Manager.
3. Open your domain's document root (usually public_html for the primary domain).
4. Upload this ZIP and extract it.
5. Make sure index.html is directly inside public_html, not nested inside another folder.
6. Visit your domain to test the website. Enable HTTPS/SSL in cPanel if available.

Files:
- index.html — website content, contact information and SEO metadata.
- styles.css — styling, layout and responsive behaviour.
- script.js — mobile navigation and Hindi/English language switch.
- assets/favicon.svg — browser tab icon.
